# RepoOps Demo Weather Station

Petit projet public de démonstration destiné à alimenter les scénarios de présentation de RepoOps.

## Objectif

Ce dépôt ne cherche pas à représenter un produit métier complet. Il sert de terrain vivant pour montrer :

- des pull requests ouvertes ;
- des vérifications CI ;
- des mises à jour de dépendances ;
- des décisions de revue ou de correction ;
- des signaux exploitables par RepoOps.

## Projet

L’application est une interface web légère de suivi météo, construite avec React, Vite et TypeScript.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Intention de démonstration

Le dépôt est volontairement simple pour que les événements GitHub restent faciles à lire. La valeur de démonstration vient surtout des évolutions, des pull requests et des contrôles associés.
